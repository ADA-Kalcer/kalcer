# User Guide

Complete guide to using all of Arca's features for exploring Bali's
cultural heritage.

## Overview

This comprehensive guide covers everything you need to know about using
Arca effectively, from basic navigation to advanced features.

## Core Features

Arca provides several ways to explore and learn about Bali's *patung*:

### Interactive Map
The main interface shows your location and nearby statues with detailed
markers indicating different types of *patung*.

### Audio Tours
Hands-free exploration with automatic narration as you encounter statues
along your journey.

### Detailed Information
Rich cultural and historical data about each statue, including stories,
significance, and construction details.

### Personal Collections
Bookmark and organize statues that hold special meaning or interest for
you.

## Navigation Tips

### Using the Map
- **Zoom**: Pinch to zoom in/out for better visibility
- **Pan**: Drag to explore different areas
- **Markers**: Different colors indicate ritual vs monumental statues

### Search and Filter
- Search by statue name or location
- Filter by category (ritual/monumental)
- Sort by distance or cultural significance

## Cultural Etiquette

When visiting *patung* sites:
- Respect sacred spaces and ongoing ceremonies
- Follow local customs and dress codes
- Ask permission before taking photos at ritual sites
- Maintain respectful distance during religious activities
